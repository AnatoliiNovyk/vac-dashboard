# Обмежити Manager View вертикаллю користувача

Summary:

- Уніфіковано фільтрацію Manager View так, щоб незалежно від ролі (менеджер, HR, HR Head) відображалися лише підлеглі поточного користувача та він сам.
- Використовується існуючий BFS (`getManagerEmployees`) для побудови набору нащадків, що забезпечує цілісну вертикаль.
- Для HR Head додатково обмежено результат співробітниками його департаменту, щоб Manager View не показував глобальний зріз.

Files changed (paths/lines):

- app.js (функція `getEmployeesForRendering` тепер завжди обмежує Manager View переліком `allowedIds`, сформованим із BFS-вертикалі, та звужує результат для HR Head до власного департаменту).

Data/Rules/Functions:

- Не змінювались; очікується подальша інтеграція з кешем `teamTrees`/callable `getManagerTeam` при рефакторингу.

Tests/Validation:

- Manual: запустити емулатори, увійти як менеджер — переконатись, що у Manager View лише підлеглі; увійти як HR Head — Manager View показує тільки вертикаль його відділу; після зміни фільтрів дані не виходять за межі вертикалі.

Risks & Rollback:

- Помилка у побудові вертикалі може призвести до пустого Manager View у користувачів без прямого підпорядкування; відкат — повернути попередню умову фільтрації в `getEmployeesForRendering`.
