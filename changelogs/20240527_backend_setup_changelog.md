# Changelog: Налаштування бекенду та заповнення даними

## Виконані роботи

### 1. Ініціалізація та налаштування Firebase/Firestore
- Ініціалізовано проект Firebase.
- Налаштовано та ініціалізовано сервіс Cloud Firestore.
- Створено та розгорнуто правила безпеки для Firestore, що дозволяють доступ до даних.
- Проведено налагодження та виправлення помилок, пов'язаних з активацією Firestore API та налаштуванням правильного регіону бази даних (`nam5`).

### 2. Створення та запуск скрипту для заповнення бази даних
- Створено скрипт `seed.js` для автоматичного заповнення бази даних Firestore.
- До скрипту додано логіку для завантаження даних про співробітників, відділи та періоди відпусток.
- Встановлено залежність `firebase-admin` для взаємодії з Firebase.
- Скрипт успішно виконано, і початкові дані було завантажено до Firestore.

## Наступні кроки
- Підключити фронтенд-додаток до Firestore для отримання та відображення даних в реальному часі.
- Реалізувати логіку визначення статусу співробітника ("На роботі", "У відпустці", "Заплановано") на основі даних з Firestore.
