# Changelog: 2025-11-06 — Впровадження рендеру вкладок за ролями

## Summary
- Додано автоматичне створення тестових департаментів у Firestore Emulator через `scripts/seed.js`.
- Департамент випадково призначається кожному співробітнику при генерації тестових даних.
- Додано базову функцію рендеру вкладок у `setupTabs` в `app.js` згідно ролі користувача (HR, Manager, Employee).
- Вкладки тепер відображаються після логіну відповідно до claims/roleFlags.

## Files changed
