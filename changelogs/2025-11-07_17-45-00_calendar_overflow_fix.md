# Calendar: keep grid fully visible

## Summary

- Розблоковано горизонтальне відображення календарної сітки, щоб усі 7 колонок завжди вміщалися без обрізання.
- Забезпечено адаптивність: на desktop календар займає до ~30% ширини, на mobile розширюється на 100% без перекриттів.

## Changes

- `style.css` – додано `overflow-x: auto` для `calendar-section`, мінімальні ширини колонок у `.calendar-grid`, а також гнучке поводження на малих екранах.

## Tests / Validation

1. Перевірити HR View на desktop: видимі всі дні поточного місяця, календар не обрізаний.
2. Зменшити ширину вікна до ~768px: календар переходить під таблицю, ширина 100%, дані не виходять за межі.
3. Прокрутити горизонтально (якщо потрібно) – нічого не накладається на таблицю.
