# HR View: fix calendar/table overlap

## Summary

- Перебудовано контейнер контенту на flex-верстку з окремими колонками для календаря (≈28%) та таблиці.
- Додано внутрішній роздільник, контроль overflow і порядок шарів, щоб елементи не накладалися один на одного.

## Changes

- `style.css` – оновлено `.content-area`, `.calendar-section`, `.table-section` з flex-колонками, clamp-ширинами, separator-лінією та overflow.

## Tests / Validation

1. Відкрити HR View на desktop (≥1200px): календар займає ≤30%, таблиця розташована праворуч без перетинів.
2. Зменшити ширину до ~768px: блоки складаються у колонку, календар і таблиця не перекриваються.
3. Перевірити скрол у таблиці – горизонтальний/вертикальний працює в межах секції.

## Risks & Rollback

- Для відкату повернути `style.css` та видалити цей changelog-файл.
