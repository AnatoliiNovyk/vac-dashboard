# Changelog: 2025-12-03 04:26 — Приховання колонок в Manager View

## Summary

- Приховано колонку "ПІДРОЗДІЛ" в Manager View (не логічна - всі підлеглі з одного департаменту)
- Приховано колонку "ДІЇ" в Manager View (порушує ТЗ - менеджер не має права редагувати відпустки)

## Changes Made

### Manager View - Hide Department Column
**Issue**: Колонка "ПІДРОЗДІЛ" в Manager View не має сенсу, бо менеджер бачить тільки своїх підлеглих з одного департаменту (завжди одне значення).

**Solution**:
- Додано умову `if (appState.currentTab !== "Manager View")` перед рендерингом Department колонки
- Колонка тепер показується тільки в HR View та My View

### Manager View - Hide Actions Column  
**Issue**: Колонка "ДІЇ" з кнопками редагування порушує ТЗ - менеджер не має права редагувати відпустки співробітників (тільки переглядати).

**Solution**:
- Обгорнуто весь блок Actions в умову `if (appState.currentTab !== "Manager View")`
- Actions колонка (з кнопками Info та Edit) тепер показується тільки в HR View та My View
