# Calendar: square desktop layout

## Summary

- Зроблено календар більш квадратним: ширина 28 % супроводжується співвідношенням сторін 1:1.05 і обмеженням висоти.
- На мобільних обмеження знімаються, тож блок переходить у повну ширину без спотворень.

## Changes

- `style.css` – додано `aspect-ratio` та `max-height` для `.calendar-section`, прибрано `height: fit-content` і скинуто обмеження в mobile-breakpoint.

## Tests / Validation

1. HR View ≥1280 px: календар виглядає майже квадратним, не витягнутий вертикально.
2. Ширина <1024 px: блок календаря займає 100 %, без артефактів у висоті.

## Risks & Rollback

- Для відкату повернути зміни у `style.css` й видалити цей changelog.
