# Employee View: Minimal UI

## Summary
Відповідно до системного промпта, для Employee (My View) залишено лише:
- Ім'я та роль (текст)
- Календар своїх відпусток
- Таблиця своїх відпусток

Всі зайві блоки (статистика, фільтри, глобальні таблиці) приховано. Для HR/Manager — повний функціонал згідно ролі.
