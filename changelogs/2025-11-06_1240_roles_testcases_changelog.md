# Changelog: 2025-11-06 12:40 — Тестові сценарії для ролей

## Summary

- Додано тестові сценарії для ручної/автоматичної перевірки всіх ролей: HR, Manager, Employee.
- Описано очікувану поведінку для вкладок, доступів, фільтрів, календаря, залишку, статусів.

## Test Cases

### HR
- Вкладки: HR, My View (HR-менеджер: HR, Manager, My View)
- Доступ: бачить всіх співробітників, може фільтрувати по департаменту/статусу
- Залишок: коректно обчислюється для кожного співробітника
- Статуси: лише "У відпустці", "Заплановано", "На роботі"
- Календар: не відображається

### Manager
- Вкладки: Manager, My View
- Доступ: бачить лише підлеглих (фільтр по manager_id), може фільтрувати по департаменту/статусу
- Залишок: коректно обчислюється для підлеглих
- Статуси: лише "У відпустці", "Заплановано", "На роботі"
- Календар: не відображається

### Employee
- Вкладка: My View
- Доступ: бачить лише себе
- Залишок: коректно обчислюється
- Статус: лише свій
- Календар: відображає власні відпустки
