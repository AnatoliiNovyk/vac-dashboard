# BAS Export Dialog & Callable Integration

## Summary

- Додано модальне вікно експорту BAS з вибором періоду, статусів та підрозділу.
- Реалізовано генерацію CSV/JSON/XML на фронтенді з фільтрами та підсумковим логом.
- Оновлено Cloud Function-клієнт `exportToBAS` у модулі `bas-integration.js`.

## Files changed

- `index.html` — додано структуру модального діалогу експорту BAS та пов’язані контролі.
- `style.css` — стилі для діалогу, чипів статусів та повідомлення про помилки.
- `app.js` — логіка відкриття/закриття діалогу, збирання фільтрів, виклики `exportToBAS`, логування результатів.
- `bas-integration.js` — реалізація `exportToBAS`, підтримка форматів CSV/JSON/XML, агрегація підсумків та блоби для завантаження.

## Data / Rules / Functions

- Схеми Firestore та Security Rules не змінювались.
- Нові мережеві виклики використовують уже наявний callable `importBasData`; експорт працює виключно на клієнті.

## Tests / Validation

- Автоматизовані тести не запускались.
- Ручну перевірку (Firebase Emulator Suite + завантаження файлів) треба виконати окремо.

## Risks & Rollback

- Ризик великих наборів даних (великий CSV може спожити багато пам’яті у браузері). Відкат: повернути попередні версії `app.js`, `bas-integration.js`, `index.html`, `style.css`.
- Потрібно перевірити локалізацію форматів дат у різних таймзонах перед продакшн-деплоєм.
