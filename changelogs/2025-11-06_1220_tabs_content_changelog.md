# Changelog: 2025-11-06 12:20 — Рендер контенту вкладок HR/Manager/My View

## Summary

- Додано контейнер для контенту вкладок у `index.html` (`tab-content`).
- В `app.js` реалізовано функцію `renderTabContent` для рендеру базового контенту вкладок:
    - HR: таблиця всіх співробітників (ім'я, відділ, залишок, статус).
    - Manager: таблиця підлеглих (фільтр по manager_id).
    - My View: персональна інформація поточного користувача.
- Вкладки автоматично перемикають контент згідно ролі.

## Files changed

- `index.html`: додано `tabs-nav` та `tab-content` у dashboard-container.
- `app.js`: додано функцію `renderTabContent`, інтегровано з логікою вкладок.

## Data/Rules/Functions

- Дані: використовуються employees з Firestore, залишок обчислюється як total_vacation_days - used_vacation_days.
- Відображення контенту строго за ролями.
