# Прибрати колонку та фільтр підрозділу з Manager View

Summary:

- Manager View більше не відображає колонку "Підрозділ" у таблиці підлеглих, фокусуючись на релевантних даних вертикалі.
- Для Manager View прибрано фільтр "Підрозділ"; панель фільтрів приховується, якщо немає доступних контролів.
- Під час перемикання на Manager View очищається відфільтрований підрозділ, щоб уникнути порожніх результатів після попередніх вкладок.
