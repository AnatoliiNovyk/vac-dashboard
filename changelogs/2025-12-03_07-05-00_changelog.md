# Changelog: 2025-12-03 07:05 — Додано статистичний блок "На роботі"

## Summary

- Додано 4-й статистичний блок "На роботі" в HR View та Manager View
- Блок відображає кількість співробітників, які зараз знаходяться на робочому місці (статус "На роботі")

## Changes Made

### UI Module (`js/modules/ui.js`)
**Requirement**: Додати 4-й блок статистики "На роботі" в секцію інформерів.

**Solution**:
- Оновлено функцію `renderStats`:
  - Додано розрахунок `working` як різницю: `totalEmployees - onVacation - planned`. Це забезпечує математичну точність і уникає проблем з рядковим порівнянням.
  - Додано об'єкт картки `{ label: "На роботі", value: working, icon: "fa-briefcase", color: "teal" }` до масиву `stats`

**Result**:
- Тепер відображається 4 картки:
  1.  Співробітників (Всього)
  2.  У відпустці
  3.  Заплановано
  4.  **На роботі** (Нова)

## Verification

Протестовано:
- ✅ Manager View: Показує 4 картки. Для тестового менеджера (2 співробітника): 2 Співробітників, 0 У відпустці, 0 Заплановано, **2 На роботі**.
- ✅ HR View: Показує 4 картки з даними по всій компанії.
- ✅ Адаптивність: Картки автоматично розміщуються в сітці (`grid-template-columns: repeat(auto-fit, minmax(170px, 1fr))`).
