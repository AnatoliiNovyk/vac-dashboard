# Changelog: 2025-12-03 11:40 — Виправлено розбіжність даних в Manager View

## Summary

- Виправлено проблему, коли в Manager View відображалися застарілі або неповні дані про співробітників (статус, відпустки) порівняно з HR View.
- Тепер Manager View використовує збагачені дані (з розрахованими статусами та періодами відпусток).

## Changes Made

### UI Module (`js/modules/ui.js`)
**Requirement**: Дані в Manager View не співпадають з HR View (різні статуси, відсутня інформація про найближчу відпустку).

**Cause**: Функція `getManagerEmployees` повертала "сирі" дані з Firestore (`appData.employees`), які не містили обчислених полів (`computedStatus`, `vacationPeriods`), що додаються функцією `enrichEmployeeData`.

**Solution**:
- Оновлено `getEmployeesForView`:
  - Отримуємо структуру команди (список співробітників) через `getManagerEmployees`.
  - Витягуємо ID цих співробітників.
  - Фільтруємо вже збагачений масив `employees` (який містить повні дані), залишаючи тільки тих, хто є в команді менеджера.

**Result**:
- Manager View тепер відображає коректні статуси ("У відпустці", "Заплановано") та дати найближчих відпусток, ідентичні тим, що в HR View.
- Статистика в Manager View також буде коректною, оскільки базується на правильних статусах.
